Redis 的数据结构

具体的去查手册，这种东西写也写不完

String

SET：设置键的字符串值

GET：获取键的值

APPEND：在已有字符串后追加内容

STRLEN：获取字符串长度

MSET：一次设置多个键值对

MGET：一次获取多个键的值

List

LPUSH：在列表头部插入元素

RPUSH：在列表尾部插入元素

LPOP：移除并返回列表头部元素

RPOP：移除并返回列表尾部元素

LRANGE：获取列表指定范围内的元素
